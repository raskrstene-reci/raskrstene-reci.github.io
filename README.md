# Раскрштене речи

блог с циљем да себи, првенствено, забележим неке од речи и израза из свакодневне употребе а који - кад се мало промисли - имају сасвим друкчије и изненађујуће значење;

најчешће јер нису славенског порекла и не уклапају се у српски језик.
